# Clustta Plugins

Official release packages for Clustta creative application plugins.

## Downloads

Plugin ZIP packages are published as GitHub Release assets. They are not committed to the repository, which keeps the Git history small and gives every package a stable, versioned download URL.

Release tags use `<plugin>-v<version>`, for example `blender-v1.2.9`. Package filenames retain the names produced by each plugin project.

Available plugins:

- Blender
- Cavalry
- FreeCAD
- GIMP
- Houdini
- Inkscape
- Krita
- Nuke
- Photoshop

See [clustta.com/plugin](https://clustta.com/plugin) for the current downloads and [docs.clustta.com/features/plugins](https://docs.clustta.com/features/plugins) for installation instructions.
